Set up traps

Add a camera to the orchard or take one out. ESP32 cameras send their photos through a hub: a Raspberry Pi with no camera, on mains power, in Wi-Fi range of them. A new camera switched on near a hub shows up here by itself, and a hub is added with the pairing code on its sticker. The hub picks up changes here within a minute.

Plug the ESP32 into a computer with the repo and PlatformIO, and run this from the repo:

device/esp32-node/flash-camera.sh {{ t.id }} {{ new_key.key }}

It puts the id and key in node_config.h and flashes the board. The first time on a computer it asks for the hub's Wi-Fi name and password once. Then hang the camera and power it: hub {{ t.hub_id }} accepts it within a minute, with no change on the hub.

Or by hand

In device/esp32-node/include/node_config.h, then pio run -t upload:

#define TRAP_ID "{{ t.id }}"
#define API_KEY "{{ new_key.key }}"
{% elif t.kind == 'hub' %}

On the hub Pi (online, with Tailscale), from the repo's device/ folder:

sudo ./install-hub.sh {{ t.id }} {{ new_key.key }} {{ server_url }}

It installs the gateway, writes these into /etc/sentinel/config.toml and starts it. The hub shows as online here within a minute, and then it can be picked as the hub for ESP32 cameras. Set its Wi-Fi for the cameras as in docs/esp32-traps.md.

Or by hand

In /etc/sentinel/config.toml, then sudo systemctl restart sentinel-gateway:

trap_id = "{{ t.id }}"
api_key = "{{ new_key.key }}"
server_url = "{{ server_url }}"
